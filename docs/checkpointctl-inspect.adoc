= checkpointctl-inspect(1)
include::footer.adoc[]

== Name

*checkpointctl-inspect* - display low-level information about a container checkpoint

== Synopsis

*checkpointctl inspect* [_OPTION_]...  _FILE_

== Description

Inspect container checkpoint archives. Reading command lines and environment
variables requires memory pages in the archive. CRIU LZ4-compressed pages
are decoded automatically and require `checkpoint/inventory.img`.

The default output shows `CRIU compression: Enabled` or `CRIU compression: Disabled`.
JSON output includes the boolean field `criu_compression`. This setting describes
CRIU memory page compression, independently of archive compression. Archives
without `checkpoint/inventory.img` are reported as compression disabled for
compatibility with older checkpoints. Invalid inventory metadata returns an error.

== Options

*-h*, *--help*::
  Show help for checkpointctl inspect

*--all*::
  Show all information about container checkpoints

*--files*::
  Display the open file descriptors for processes in the container checkpoint

*--format*=_FORMAT_::
  Specify the output format: tree or json (default "tree")

*--metadata*::
  Show metadata about the container

*--mounts*::
  Display an overview of mounts used in the container checkpoint

*-p, --pid*=_PID_::
  Display the process tree of a specific PID

*--ps-tree*::
  Display an overview of processes in the container checkpoint

*--ps-tree-cmd*::
  Display an overview of processes in the container checkpoint with full command line arguments

*--ps-tree-env*::
  Display an overview of processes in the container checkpoint with their environment variables

*--sockets*::
  Display the open sockets for processes in the container checkpoint

*--stats*::
  Display checkpoint statistics
