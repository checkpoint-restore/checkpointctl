= checkpointctl-memparse(1)
include::footer.adoc[]

== Name

*checkpointctl-memparse* - analyze container checkpoint memory

== Synopsis

*checkpointctl memparse* [_OPTION_]... _FILE_

== Description

Display process memory sizes, write memory contents, or search memory in a
container checkpoint archive. Memory sizes refer to memory before compression.

CRIU LZ4-compressed memory pages are decoded automatically and require
`checkpoint/inventory.img`. Page compression is separate from archive compression.

Each checkpoint's output shows `CRIU compression: Enabled` or
`CRIU compression: Disabled`. Older checkpoints without `inventory.img` show
compression as disabled. With `--output`, the indicator is printed to the
terminal and is not included in the memory output file.

The memory pages being read must be present in the archive.

== Options

*-h*, *--help*::
  Show help for checkpointctl memparse

*-o, --output*=_FILE_::
  Specify the output file to be written to

*-p, --pid*=_PID_::
  Specify the PID of a process to analyze

*-s, --search*=_STRING_::
  Search for a string pattern in memory pages

*-r, --search-regex*=_REGEX_::
  Search for a regex pattern in memory pages

*-c, --context*=_CONTEXT_::
  Print the specified number of bytes surrounding each match
