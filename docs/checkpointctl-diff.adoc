= checkpointctl-diff(1)
include::footer.adoc[]

== Name

*checkpointctl-diff* - show changes between two container checkpoints

== Synopsis

*checkpointctl diff* [_OPTION_]... _CHECKPOINT_A_ _CHECKPOINT_B_

== Description

Compare two container checkpoints and show differences in:

* Process tree (new/removed/modified processes)
* File descriptors (opened/closed files)
* Sockets (new/removed network sockets)
* Stored memory page-image sizes

Command lines and environment variables are read from memory pages in each
archive. CRIU LZ4-compressed pages are decoded automatically and require
`checkpoint/inventory.img`.

Compression can change stored page-image sizes without changing process
memory. The `size_change_mb` field in JSON output is measured in MiB.

Each checkpoint's details show `CRIU compression: Enabled` or
`CRIU compression: Disabled`. JSON output includes the boolean field
`criu_compression` in both `checkpoint_a` and `checkpoint_b`. This setting
describes CRIU memory page compression, independently of archive compression.
Archives without `checkpoint/inventory.img` are reported as compression
disabled for compatibility with older checkpoints.

`Container created` shows when the container was created, so it is the same
for checkpoints of the same container. JSON output keeps this timestamp in
the `created` field of `checkpoint_a` and `checkpoint_b`.

`Checkpoint data size` is the combined size of files under `checkpoint/`,
including memory images and CRIU metadata. It reflects CRIU page compression,
but not compression of the archive. JSON output keeps this value in `total_size`.

== Options

*-h*, *--help*::
  Show help for checkpointctl diff

*--files*::
  Include file descriptors in the diff

*--format*=_FORMAT_::
  Specify output format: tree or json (default "tree")

*--ps-tree-cmd*::
  Include full command lines in process tree diff

*--ps-tree-env*::
  Include environment variables in process tree diff

*--show-unchanged*::
  Show entries that are identical between the two checkpoints

*--sockets*::
  Include sockets in the diff

== Examples

Compare two checkpoints with default tree view:

  $ checkpointctl diff checkpoint1.tar checkpoint2.tar

Show differences including file descriptors and sockets:

  $ checkpointctl diff --files --sockets checkpoint1.tar checkpoint2.tar

Include command line arguments and unchanged entries:

  $ checkpointctl diff --show-unchanged --ps-tree-cmd checkpoint1.tar checkpoint2.tar

Output differences in JSON format:

  $ checkpointctl diff --format json checkpoint1.tar checkpoint2.tar
